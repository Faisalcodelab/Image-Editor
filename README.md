🖼️ Quick Image Editor
A Quick Image Editor that allows users to apply various filters, rotate, and flip images interactively.
It also supports uploading custom images and saving the edited results. The project comes with a set of intuitive controls that make editing easy for users of all levels.

🚀 Features
🖌️ Filters: Apply Brightness, Saturation, Inversion, and Grayscale to images.
🔄 Rotate & Flip: Rotate images to the left/right or flip horizontally/vertically.
🖼️ Image Preview: Preview the image with applied filters and effects.
📂 Upload & Save: Upload custom images and save the edited version to your device.
🎨 Real-time update of filter adjustments with a smooth user interface.

🎮 How to Use
Open the HTML file in your browser to start using the image editor.
Upload an image by clicking the "Upload Image" button and selecting an image from your device.
Use the filter options (Brightness, Saturation, Inversion, Grayscale) to adjust the image's appearance in real time.
Rotate and flip the image using the corresponding buttons for rotation or reflection.
Once you're satisfied with the changes, click Save Changes to download the edited image.

🛠️ Technologies Used
HTML – Structure for the editor, filter controls, and image preview
CSS – Styling for the image editor interface and layout
JavaScript – Image manipulation and interaction with filters, rotation, and image upload

File Input: Allows users to upload their own images.
Image Filters: JavaScript-driven filter adjustments such as brightness and grayscale.

🔧 Instructions
The image is displayed with applied filters that can be adjusted using range sliders.
Rotation and flip options let users change the orientation of the image.
The Save button allows users to download the modified image to their local machine.
The Reset button clears any changes made, allowing users to start from the original uploaded image.
